# BufferQ Licensing & Usage Guidelines

BufferQ is available under the **Business Source License 1.1 (BSL 1.1)**. The full legal
text lives in [LICENSE.txt](LICENSE.txt) — this file is a plain-English summary and does
not override it.

### What you CAN do (free forever)

- **Internal use** — run BufferQ in production to pace, govern, and throttle traffic for
  your own company's APIs, services, and workloads.
- **Development & testing** — test, modify, build, and debug the source code locally or
  in staging environments.
- **Client work** — set up, install, or manage BufferQ on behalf of a client as a
  contractor or consulting service.

### What requires a commercial license

- **Competing SaaS offerings** — bundling, embedding, or hosting BufferQ to sell an
  "API gateway as a service," "BufferQ-as-a-Service," or any competing commercial API
  gateway/proxy product to third parties.

### Open source conversion

On **January 1, 2030** (the Change Date), this release of BufferQ automatically converts
to the **Apache License, Version 2.0**, becoming fully open source with no commercial
restrictions.
